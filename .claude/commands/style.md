このセッション中、生成する全てのテキスト(コード, コメント, ドキュメント, todo, commit メッセージ等)に以下のルールを適用せよ。

## 記号

- 半角で同じ形状の存在する記号は半角を使う。全角禁止。
    - 例: () を使う。（）は使わない
    - 例: / を使う。／は使わない
    - 例: : を使う。：は使わない
    - 例: , を使う。、は状況により許容(日本語の読点として)
- 例外: ！ と ？ は日本語の文章中では全角を使う

## 矢印

- ASCII で表現する: -> または --> を使う。→ 等の Unicode 矢印は使わない
